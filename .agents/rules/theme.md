# DSD Resort Admin - System Design & Color Theme Guidelines

Always enforce and strictly apply the following color palette and UI theme standards across all components, pages, layout files, dialogs, buttons, text elements, and navigation links:

## Core Color Palette
- **Navy Blue**: `#092968` (Primary brand color for headers, main titles, primary text accents, active navigation indicators, and prominent elements)
- **Orange**: `#F26E22` (Secondary accent color for buttons, highlights, badges, focus states, interactive hover effects, and call-to-actions)
- **White**: `#FFFFFF` (Card backgrounds, page containers, crisp text on dark backgrounds)
- **Black / Dark Gray**: `#0B1B3D` / `#1F2937` / `#374151` (Body text, subheadings, labels)

## Component & Styling Rules
1. **Buttons**: Use `#F26E22` as the primary background color with white text, and `#D95C1A` on hover state.
2. **Headings**: Primary titles should feature `#092968` with accent highlights in `#F26E22`.
3. **Form Focus & Borders**: Form input focus states and hover borders should use `#F26E22`.
4. **Links**: Interactive text links should default to Navy (`#092968`) or `#0B1B3D` and transition to `#F26E22` on hover.
